# Font tự phục vụ của DayTrail

Các file WOFF2 trong thư mục này được tải từ Google Fonts và được bundle cùng frontend; ứng dụng không gọi dịch vụ font bên ngoài khi chạy.

- **Be Vietnam Pro** — giao diện, trọng lượng 400/600/700; copyright 2021 The Be Vietnam Pro Project Authors.
- **Lora** — tiêu đề, variable weight 400–700; copyright 2011 The Lora Project Authors.
- **Patrick Hand** — nội dung cá nhân dạng viết tay, trọng lượng 400; copyright 2010–2012 Patrick Wagesreiter.

Cả ba font có subset Vietnamese và dùng giấy phép SIL Open Font License 1.1 trong [OFL-1.1.txt](OFL-1.1.txt). Metadata nguồn:

- https://github.com/google/fonts/tree/main/ofl/bevietnampro
- https://github.com/google/fonts/tree/main/ofl/lora
- https://github.com/google/fonts/tree/main/ofl/patrickhand
